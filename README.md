# Age of Exploration Study Guide

A study site for the Age of Exploration unit test. It has two sections:

- **Learn**: the eight explorers (who sent them, where they went, when), each with a map, plus the Columbian Exchange, the Triangular Trade, culture in the Americas, and the Maya, Aztec and Inca empires.
- **Practice test**: multiple-choice and map questions with instant feedback and a review of missed questions.

Maps are drawn from [Natural Earth](https://www.naturalearthdata.com/) coastline data (public domain).

It's a single self-contained `index.html`. Open it in any browser, or view it on GitHub Pages.
